# 🏨 Hospitality Analytics – Data Analyst Project

## 📌 Project Overview

This project focuses on analyzing hospitality data to identify revenue trends, hotel and city performance, customer-related patterns, and other key business insights.

The project demonstrates end-to-end data analytics skills using **Excel, SQL, Power BI, and Tableau**.

## 🎯 Project Objective

The main objective of this project is to analyze hospitality data and provide meaningful insights that can help management understand business performance and make data-driven decisions.

## 🛠️ Tools & Technologies

* **Excel** – Data cleaning, analysis, calculations, and reporting
* **SQL** – Data querying and business analysis
* **Power BI** – Interactive dashboards and KPI visualization
* **Tableau** – Interactive data visualization and dashboard creation

## 📊 Key KPIs & Analysis

The project analyzes important business metrics such as:

* Total Revenue
* Revenue by City
* Revenue by Hotel
* Monthly Revenue Trends
* Revenue by Duration
* Hotel Performance
* City Performance
* Other relevant hospitality performance metrics

## 🔍 Key Analysis

The analysis was performed to identify:

* Which city generates higher revenue
* Which hotel generates higher revenue
* Which months generate higher revenue
* How revenue varies based on duration
* Important trends and patterns in hospitality performance
* Areas where business performance can be improved

## 🗄️ SQL Analysis

SQL was used to perform business-oriented data analysis, including:

* Filtering and sorting data
* Aggregations using `SUM`, `AVG`, `COUNT`, `MIN`, and `MAX`
* `GROUP BY` and `HAVING`
* Joins
* Subqueries
* CTEs
* Window functions
* Ranking and comparative analysis
* Revenue and performance analysis

## 📈 Power BI Dashboard

Power BI was used to create an interactive dashboard containing key performance indicators, charts, trends, and business insights.

The dashboard helps users understand hospitality performance through interactive visualizations and filters.

## 📊 Tableau Dashboard

Tableau was used to create additional interactive visualizations for analyzing hospitality trends and comparing business performance across different dimensions.

## 💡 Recommendations

Based on the analysis, businesses can:

* Monitor high-performing cities and hotels
* Analyze monthly revenue trends for better planning
* Identify periods of lower performance
* Monitor duration-based revenue patterns
* Use dashboard insights to support data-driven decision-making
